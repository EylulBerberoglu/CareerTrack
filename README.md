# CareerTrack — Job Application Tracker

CareerTrack is a responsive web application designed to help users organize, manage, and track their job applications throughout the recruitment process.

Built with **React and Vite**, the application provides an intuitive dashboard, Kanban board, application statistics, and an interview calendar.

## Features

- **Dashboard:** Overview of total applications, active applications, interviews, and recent activity.
- **Application Management:** Add, view, edit, and delete job applications.
- **Search and Filtering:** Search applications by company or position, filter by status, and sort by date.
- **Kanban Board:** Manage applications across four stages: Applied, Interview, Accepted, and Rejected.
- **Interview Calendar:** Schedule and view upcoming interviews.
- **Statistics:** Visualize application statuses and monthly application activity through interactive charts.
- **LocalStorage:** Save application data locally in the browser.
- **Responsive Design:** Clean and accessible interface for different screen sizes.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/EylulBerberoglu/CareerTrack.git
```

Navigate to the project directory:

```bash
cd CareerTrack
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## Data Storage

CareerTrack uses browser LocalStorage to store job applications. Data remains available after refreshing the page but is specific to the browser and device. No backend server or user authentication is required.
